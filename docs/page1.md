# 1ページ目: 設定画面

## 役割

その日のゲームの基本設定(日付、参加者、ウマ)を入力する。

## 表示タイミング

- 0ページ目の認証成功直後
- レジューム時に `currentPage === 1` だった場合

## 画面要素

### 入力欄

- **日付**: 日付入力(`<input type="date">`)、デフォルトは今日
- **参加者**: 4つのテキスト入力(プレイヤー1〜4の名前)
- **ウマ1**: 数値入力(1位⇔4位の点差、デフォルト10)
- **ウマ2**: 数値入力(2位⇔3位の点差、デフォルト5)

### ボタン

- **ゲーム開始**: 入力内容を確定して2ページ目へ

## 処理フロー

1. ユーザーが各項目を入力
2. ゲーム開始ボタン押下
3. バリデーション:
   - 4人の名前がすべて入力されているか
   - ウマ1、ウマ2が正の整数か
4. ローディング表示
5. GASに `action: 'create'` でリクエスト → スプレッドシート新規作成、IDを取得
6. stateに設定値とspreadsheetId/sheetUrlを保存
7. `action: 'save'` で初期データを書き込み(任意、createで初期書き込みされる場合は不要)
8. localStorage更新
9. 2ページ目に遷移(`currentPage = 2`)

## バリデーション

- 4人の名前がすべて入力されるまで「ゲーム開始」ボタンは無効
- 日付未入力でも無効
- ウマは正の整数のみ

```
│ 麻雀成績入力 [同期][設定]    │
├────────────────────────────┤
│                            │

│  [ 2026/05/03 ]            │
│                            │
│  参加者                     │

│  プレイヤー3 [          ]   │
│  プレイヤー4 [          ]   │
│                            │
│  ウマ1 (1位⇔4位)  [ 10 ]   │
│  ウマ2 (2位⇔3位)  [  5 ]   │

```

## 関連state

```js
{
  date: '2026-05-03',
  players: ['いけだ', 'わたなべ', 'きよし', 'うちだ'],
  uma1: 10,
  uma2: 5,
  spreadsheetId: '1abc...',  // create成功時に保存
  sheetUrl: 'https://...',
  currentPage: 1,             // ゲーム開始で 2 に切替
}
```

## エラー処理

- `create` リクエスト失敗時:
  - エラーメッセージを表示「スプレッドシート作成に失敗しました」
  - リトライ可能な状態に戻す
  - 入力内容は保持

## 注意事項

- ゲーム開始後は基本的にこのページに戻らない(ウマ等の変更は想定しない)
- もし変更したい場合はスプレッドシート側で直接編集
